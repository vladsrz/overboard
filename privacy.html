Privacy

Play activity, device type and country are collected. No names, unless you put yours on the leaderboard.

What is sent

  • That someone opened the game, and when a match finishes (rounds, falls, pickups, who won — seats are “person” or a bot, never a typed name).
  • A random id made in this browser, so repeat visits can be counted without knowing who you are.
  • Rough device type (touch or not) and country, from the network path to the game server.
  • For the weekly leaderboard: each match you win in a room or Play online, counted against that random id and kept for eight weeks. Up to ten wins against only bots count per UTC day. Nothing is shown until you add a name.
  • A name, only if you add one to the leaderboard. Anyone can see it there, next to your wins this week. Change it or take it off on the leaderboard page; it is also dropped eight weeks after your last win.
  • If a leaderboard name needs moderation, its browser id is kept on a block list so it cannot add another name. The id is not shown publicly.

What is not

  • Any other name, room codes you type, or anything else you enter.
  • IP addresses in the play record.

Why

To see how the game is played and tune it, and to run the leaderboard. The leaderboard only counts matches the game server ran itself, so a win cannot be made up.

On this device

A longer record of matches stays in this browser’s local storage so you can review it at dev/stats.html on the same address. Clearing site data clears it.
